# Submission checklist (PayPal AI Hackathon)

Deadline: **12 Nov 2026, 12:00 PST = 21:00 in Benin.** Aim to submit by 10 Nov.
Source: the official rules, https://paypalaihackathon.devpost.com/rules. Re-read them before submitting.

## Must have
- [ ] PayPal is central: sandbox orders are really created, not just mentioned
- [ ] An AI model really decides what the agent does
- [ ] Working demo that judges can run or open (hosted URL, or run instructions in the README). No static mockup
- [ ] Public repository, **open source licence visible in the About section** (MIT)
- [ ] README with setup and run instructions, and how PayPal and AI are used
- [ ] Text description of features and functionality
- [ ] Names of the AI tools and services used, and how
- [ ] Demo video **under 3 minutes**, public on YouTube, showing the project working
- [ ] Everything in English (or an English translation)

## Integrity
- [ ] Numbers in the video and README are measured, not typed in by hand
- [ ] Repeat each live attack several times and report rates (models are not deterministic)
- [ ] Known gaps are stated openly (see README)

## Safety
- [ ] Sandbox only. No real money, no real merchants
- [ ] No imitation of PayPal's checkout pages or logos
- [ ] Secrets only in server-side environment variables. Never in the repository
- [ ] Rate-limit any public live feature so strangers cannot drain model credits

## Video
- [ ] No copyrighted music, no third-party trademarks without permission
- [ ] Shows the project functioning on the device it was built for
